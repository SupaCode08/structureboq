## สิ่งที่ตัดออกแล้ว (มีหลักฐาน)
1. **ไม่ใช่การสุ่ม:** OCR รันซ้ำได้คำเหมือนเดิมทุกคำ (รัน 3 process พร้อมกัน = รันทีละหน้า 1263/1263; ด่านรอบที่สองได้ตัวเลขเท่าเดิม)
2. **ไม่ใช่ DPI:** ความละเอียดของพิกัดคำใน cache เก่าและใหม่ลงตัวที่ความกว้างภาพ 5032 px (= 300 DPI) เท่ากัน
3. **ไม่ใช่จำนวน engine:** รันแบบ engine เดียวให้คำตรงกับ cache เก่าน้อยลง (62% เทียบ 74% ของค่าตั้งต้น) และคะแนนแย่กว่า
4. **ไม่ใช่ OCR ทีละบรรทัด (`LABELS=1`):** ตรงกับ cache เก่าเพียง 14%

## ที่เห็น
- OCR ปัจจุบันให้คำ**มากกว่า** 25–38% ต่อชุด (house_4: 3,375 → 4,186) และคำเกือบทั้งหมดเป็น ASCII ทั้งสองฝั่ง · ในชุด house_4: 76% ของคำเก่าถูกสร้างซ้ำที่ตำแหน่งและข้อความเดิม, 9% ตำแหน่งเดิมแต่ข้อความต่าง, 15% (504 คำ) หายไป, และมีคำใหม่ที่ cache เก่าไม่มี 1,276 คำ
