# MEMORY SUMMARY

## User & Identity
- **User:** Supakrit (Aoo)
- **Primary Goal:** StructBOQ - AI-assisted Construction Quantity Surveying for Concrete Structural Elements (Footings, Columns, Beams, Slabs, Stairs) according to Thai EIT (วสท.) & Comptroller General (กรมบัญชีกลาง) standards.

## Project Scope & Achievements
1. **Full Structural System Takeoff:**
   - ฐานราก (Footings: Lean concrete, Sand bedding, Formwork, Excavation/Backfill, Rebar).
   - เสา (Columns: Gross vol, Column-beam joint deduction, Rebar, Formwork).
   - คาน (Beams: Clear-span auto deduction, Stirrups, Rebar, Side/Bottom formwork).
   - พื้น (Slabs: Cast-in-place & Precast plank + Topping, Formwork).
   - บันได (Stairs: Waist slab, Treads, Landings, Handrails).
2. **Material Specifications & Factor F:**
   - Real-time user customizable rates (Concrete grade, Rebar DB/RB, Formwork, Labour).
   - Direct extraction of material specs from PDF/DXF drawings.
   - แบบ ปร.4 แยก 6 หมวด & แบบ ปร.5 คำนวณ Factor F ตามตารางกรมบัญชีกลาง (ภาษี, เงินล่วงหน้า, ดอกเบี้ย).
3. **Clean White UI & Intuitive UX:**
   - Default clean white theme with high-contrast text and smooth dark-mode toggle.
   - 3-Step Guided Workflow: 1) เลือกแบบแปลน 2) ตรวจสอบสเปก & Factor F 3) ตรวจแปลน 2D & ส่งออก ปร.4/ปร.5.
   - 2D Interactive Framing Plan with "กระดาษขาว" (White paper) & "พิมพ์เขียว" (Dark blueprint) view toggles.
   - Comprehensive 5-sheet official Excel export and printable Thai Government reports.
