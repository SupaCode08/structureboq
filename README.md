# StructBOQ — ถอดปริมาณงานโครงสร้าง ค.ส.ล. จากแบบ PDF/DXF (ทำงานในเบราว์เซอร์)

ทำงานบนเว็บล้วน: อ่านแบบ, OCR, อ่าน BOQ ปร.4, คำนวณ, ตรวจทาน และส่งออก Excel ทั้งหมดทำในเบราว์เซอร์
**ไม่ต้องใช้ AI / API key / Python / โปรแกรมในเครื่อง** — deploy เป็นเว็บ static ได้ทันที

> ทำงานต่อในโปรเจกต์นี้: อ่าน [CONTRIBUTING.md](CONTRIBUTING.md) ก่อน (กฎ, วิธีที่หน้าเว็บอัปเดตเองเมื่อ push เข้า `master`, แผนที่ความรู้)

## ใช้งาน

```bash
npm install --legacy-peer-deps
npm run datasets:sync   # คัดลอกแบบจริง + ผล OCR ที่บันทึกไว้ไปที่ public/datasets
npm run build           # ได้เว็บ static ใน dist/
npx vite preview        # ทดสอบเว็บ static ที่ http://localhost:4173
```

นำโฟลเดอร์ `dist/` ไปวางบน static hosting ใดก็ได้ (Vercel, Netlify, GitHub Pages, S3) — ไม่มี backend

## ระบบอ่านแบบทำงานอย่างไร (ไม่ใช้ AI)

| แหล่งข้อมูล | วิธีอ่าน (ในเบราว์เซอร์) |
|---|---|
| PDF ที่มีข้อความดิจิทัล | pdf.js ดึงข้อความ + ตำแหน่ง → ตารางสมาชิก (`src/pdf/scheduleParser.ts`) |
| BOQ แบบ ปร.4 (รวมฟอนต์ไทยรุ่นเก่า) | ถอดรหัสฟอนต์ (`thaiText.ts`) → แยกคอลัมน์ รายการ/จำนวน/หน่วย (`boqParser.ts`) |
| แบบ CAD ที่ตัวอักษรถูกแปลงเป็นเส้น | ดึงเฉพาะเส้นตัวอักษรจาก PDF แล้ววาดใหม่บนภาพเปล่า (`vectorText.ts`) → tesseract.js |
| แบบสแกน | เรนเดอร์หน้า → tesseract.js (แบ่งชิ้น + หมุนอ่านข้อความแนวตั้ง) |
| DXF | อ่าน TEXT/MTEXT + หน่วย `$INSUNITS` (`dxfParser.ts`) |

จากคำที่อ่านได้ ตัวอ่านกฎ (`src/pdf/sheetReader.ts`) จะ
- หาเส้นกริดจากตัวเลขบอกระยะ (2.70 | 1.50 | 2.40) + มาตราส่วนแผ่น (1:50) — ไม่ต้องอ่านวงกลมกริด
- ผูก tag กับกริด: คานบนแนวกริดระหว่างสองเสา = ช่วงนั้น, พื้นในช่อง = ช่องนั้น, ฐานรากใกล้จุดตัด
- อ่านหน้าตัดจากแบบขยาย (ขนาด + เหล็ก) และแก้คำ OCR ผิดด้วยคลัง tag ของแบบชุดนั้น (CB2→GB2)
- อ่านระดับชั้นจากรูปตัด แล้วคำนวณความสูงเสา
- **วัดรูปทรงตามมาตราส่วน** เหมือนคนใช้สเกลวัด: หน้าตัดคาน/เสาจากสี่เหลี่ยมในแบบขยาย, เสาและกริดจากสี่เหลี่ยมที่จุดตัดในผัง แล้วตรวจกับตัวเลขที่เขียน (ไม่ตรง → เข้าคิวตรวจ)

ค่าที่อ่านไม่ได้ **ไม่ถูกเดา** — ถูกส่งเข้าคิวตรวจทาน: ผู้ตรวจกรอก **ตารางหน้าตัดทีละเบอร์** (แก้ครั้งเดียว ใช้ทุกตำแหน่ง)
พร้อมหน้าแบบต้นฉบับซูมไปที่จุดที่อ่านค่า และการตรวจความครบถ้วน (เช่น "ไม่พบเสาชั้น 2", "แบบขยายมี BX แต่ไม่พบในผัง")

```bash
npm run benchmark:offline
```

## เครื่องมือเสริม (ไม่จำเป็นสำหรับเว็บ)
- `npm run dev` — เปิดเว็บแบบพัฒนา (Vite) ที่ http://localhost:5173
- `scripts/offline_ocr.ts` — รัน OCR แบบเดียวกับเบราว์เซอร์ใน Node เพื่อทำ benchmark / cache
- `npx tsx scripts/eval_reading.ts real_drawings/<ชุด> --detail` — ความแม่นยำการอ่านแบบเทียบเฉลยทีละค่า
- `npm test` — เทสต์ engine, pipeline และตัวอ่านออฟไลน์
